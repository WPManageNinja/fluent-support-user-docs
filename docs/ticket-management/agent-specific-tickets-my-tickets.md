# Agent-Specific Tickets (Assigned to Me)

Fluent Support provides a helpful view called **Assigned to Me** where you can easily see the open tickets assigned specifically to you as an agent. This article will guide you through how to use it.

## Agent Specific Tickets (Assigned to Me) 

Go to your **Fluent Support Dashboard** & click on **Tickets**.

![Tickets from Fluent Support dashboard](/images/ticket-management/daily-operations/agent-specific-tickets/my-tickets-1.webp)

In the **Ticket Filters** sidebar on the left, open the **My Work** group and click on **Assigned to Me**. You will see a list of the open tickets that are assigned only to you, and the number next to the name shows how many there are.

You can also **Filter, Sort, and Search** these tickets if needed. **Assigned to Me** works the same as the other ticket views. To learn more about how this works, read this [Documentation](/filtering-sorting-searching-tickets).

![All agent specific tickets](/images/ticket-management/daily-operations/agent-specific-tickets/my-tickets-2.webp)

::: tip
Want to jump here faster? Press **⌘ + ⇧ + M** (macOS) or **Ctrl + Shift + M** (Windows / Linux). See [Keyboard Shortcuts](/navigate-with-keyboard-shortcut). To learn about the other views in the sidebar, see [Ticket List Views](/view-manage-ticket-entries#ticket-list-views).
