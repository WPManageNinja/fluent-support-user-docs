# Navigate With Keyboard Shortcuts

Fluent Support lets you work through your tickets faster with keyboard shortcuts. You can switch ticket lists, refresh, open the reply box, and move to the next ticket without reaching for the mouse.

::: info
Keyboard shortcuts work on the **Tickets** list and inside a single ticket.
:::

## Turn On Keyboard Shortcuts

1. Go to **Settings** from your **Fluent Support** dashboard.
2. Click **Global Settings** in the left sidebar.
3. Check **Enable Keyboard Shortcuts**.
4. Click **Save Settings**.

Click the **Keyboard Shortcuts** link next to the option at any time to see the full list for macOS and Windows.

![Keyboard Shortcuts popup](/images/ticket-management/productivity-tools/navigate-with-keyboard-shortcut/keyboard-shortcuts-popup.webp)

## Before You Start

* **macOS** uses **⌘** (Command), **⌥** (Option), and **⇧** (Shift).
* **Windows and Linux** use **Ctrl** where macOS uses **⌘**, and **Alt** where macOS uses **⌥**.
* Shortcuts do not fire while you are typing in a field, such as the reply editor, a search box, or a filter. Click outside the field first, then press the shortcut.

## Tickets List Shortcuts

| Action | macOS | Windows / Linux |
|---|---|---|
| Toggle advanced filter | ⌘ + ⌥ + F | Ctrl + Alt + F |
| Refresh the list | ⌘ + ⌥ + Q | Ctrl + Alt + Q |
| Create a ticket | ⌘ + ⌥ + N | Ctrl + Alt + N |
| Reset filters | ⌘ + ⌥ + R | Ctrl + Alt + R |
| Toggle **Waiting for reply** | ⌘ + ⌥ + W | Ctrl + Alt + W |
| Go to **All Tickets** | ⌘ + ⇧ + A | Ctrl + Shift + A |
| Go to **My Tickets** | ⌘ + ⇧ + M | Ctrl + Shift + M |
| Go to **Unassigned** | ⌘ + ⇧ + U | Ctrl + Shift + U |
| Go to **Bookmarks** (Pro) | ⌘ + ⇧ + B | Ctrl + Shift + B |
| Switch status tab (such as Open, Active, Closed, All) | ⌘ + ⇧ + → / ← | Ctrl + Shift + → / ← |

## Ticket View Shortcuts

These work when you have a single ticket open.

| Action | macOS | Windows / Linux |
|---|---|---|
| Open the reply box | ⌘ + ⌥ + R | Ctrl + Alt + R |
| Open the **Notes** box (internal note) | ⌘ + ⌥ + N | Ctrl + Alt + N |
| Merge tickets (Pro) | ⌘ + ⌥ + M | Ctrl + Alt + M |
| Add bookmark (Pro) | ⌘ + ⌥ + B | Ctrl + Alt + B |
| Refresh the ticket | ⌘ + ⌥ + Q | Ctrl + Alt + Q |
| Next ticket | ⌘ + ⌥ + ↓ | Ctrl + Alt + ↓ |
| Previous ticket | ⌘ + ⌥ + ↑ | Ctrl + Alt + ↑ |
| Close the ticket | ⌘ + ⌥ + X | Ctrl + Alt + X |

### How the new ticket view shortcuts work

* **Next ticket** and **Previous ticket** move through the ticket list you opened the ticket from, in the same order. At the end of the page, you will see a note that this is the last (or first) ticket on this page.
* If you have started a reply but not sent it, Fluent Support asks before leaving the ticket. Choose **Stay** to keep working, or **Leave** to move on.
* **Close the ticket** asks you to confirm first. It does nothing on a ticket that is already closed, or if you do not have permission to manage the ticket.

## Tips And Notes

::: tip
On Windows, the old **Win** key combinations still work, but Windows often uses them for itself. **Ctrl** is the reliable choice.
:::

::: info
Shortcuts marked (Pro) need [Fluent Support Pro](/upgrade-to-fluent-support-pro-add-on). Without it, those keys do nothing.
:::
