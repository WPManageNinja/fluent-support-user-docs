# Time Sheet

The ‘**Time Sheet**’ provides a concise, tabular summary of activity across a date range. It is useful for tracking agent hours, reviewing daily output, or producing a record for payroll and management purposes.

## Accessing Time Sheet

Go to the **Reports** tab in the dashboard menu and select **Time Sheet** from the report sidebar.

![The Time Sheet report showing the date range, mailbox filter and the By Tickets view](/images/reports-analytics/reports/time-sheet/time-sheet-dashboard.webp)

## Filters

* **Date Range:** Set the reporting period. The table renders one column per day in the range, plus a **Total** column at the end.
* **Select Mailboxes:** Narrow the timesheet to one or more [business inboxes](/business-inbox). Leave it empty to include everything.

## View Modes

Use the tabs in the top right of the table to organise the same data three different ways:

* **By Tickets:** Groups activity by individual support ticket. This is the view the report opens on.
* **By Agents:** Groups activity by support staff — the view to use for payroll or workload review.
* **By Customers:** Groups activity by customer, so you can see who is consuming the most support time.

## Reading the Table

Whichever view you choose, the table lays out a **daily breakdown** across the selected range. Each row is a ticket, agent or customer; each column is a day; and the **Total** column at the end sums that row across the whole period.

If there is no recorded activity for your filters, the table shows **No Data** rather than an empty grid.

## Export

Click the **Export** button in the top right corner to download the timesheet for use in payroll or external reporting. The export reflects the date range, mailbox filter and view mode currently applied.

> [!NOTE]
> Time Sheet has no Live / Snapshot selector — it always reads live data for the date range you select.
